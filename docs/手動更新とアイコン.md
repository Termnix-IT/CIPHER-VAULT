# 手動更新とアイコン

## 利用方法

Windowsのsetup版では、ロック中も「ヘルプ」→「バージョンと更新」から更新できます。

1. 「更新を確認」を押します。
2. バージョンと変更内容を確認し、「ダウンロード」を押します。
3. 「再起動して更新」を押します。保管庫をロックして画面操作なしで更新し、自動で再起動します。再起動後はマスターパスワードで解除してください。

未保存の編集は、保存してから再試行するか、確認画面で破棄を選びます。保存中は適用できません。OSの権限確認が必要な環境では、確認画面が表示されます。

「あとで」や通常終了では適用しません。起動時の更新確認・自動ダウンロードも行いません。アプリを起動し直した場合は手動で再確認・取得します。有効なキャッシュはライブラリが再利用します。通信や検証に失敗した場合は更新せず、再試行できます。

portable版・Linux/macOS版・開発モードは配布ページから入手します。Web版にはアプリ内更新はありません。

## 更新機能のない旧版からの移行

アプリを終了し、新しいsetupを同じインストール先へ上書きします。事前のアンインストールは不要です。保管庫はインストール先とは別の `userData/data` にあり、更新のために移動・削除する必要はありません。

## 配布の条件

公開手順と添付ファイルは[リリース手順](リリース手順.md)を参照してください。安定版のみを対象とし、同じ版への更新・ダウングレードは行いません。`appId`・パッケージ名・`userData` の保存先を維持します。

既存の `electron-updater` に取得・チェックサム検証・適用を任せ、独自のexe置換は行いません。`autoDownload` と `autoInstallOnAppQuit` はfalse、適用は `quitAndInstall(true, true)` で行います。[更新フロー](ワークフロー/04-手動更新.md)も参照してください。

署名検証を無効にする設定は加えていませんが、署名証明書はリポジトリに設定していません。署名付き配布には配布環境で証明書・発行元の設定が必要です。チェックサムは発行元の保証にはなりません。

## アイコン

原本は `build/icon.png` です。銀色の鍵と黒曜石をモチーフに、内蔵imagegenで作成した透過画像を使用します。変更後は次を実行します。

```powershell
./scripts/build-icons.ps1
```

16 / 24 / 32 / 48 / 64 / 128 / 256 pxの `build/icon.ico` と、画面・favicon用 `apps/web/public/icon.png` を生成します。exeへの埋め込みには `signAndEditExecutable: true` を維持します。ショートカットだけ古い場合はWindowsのアイコンキャッシュを確認してください。

初回生成時にwinCodeSignの展開が失敗する場合は、[electron-builder issue #8149](https://github.com/electron-userland/electron-builder/issues/8149)を参照してください。公式アーカイブを取得済みなら、Windowsでは不要な `darwin` を除いて対応するwinCodeSignキャッシュへ展開できます。アイコン編集を無効にして回避しないでください。

## 検証

`npm run test:updates` で手動実行・延期・二重操作・失敗時の再試行と、準備後のサイレント適用・再起動要求を確認します。これはインストーラーを実行する試験ではありません。

公開前には専用の一時保管庫と異なる2バージョンのsetupで、実更新・自動再起動・再解除・既存データの維持を確認します。未保存編集をキャンセルできること、通常終了で適用されないことも確認します。更新取得の成功だけで実更新の確認済みとは扱いません。利用中の保管庫は使わないでください。
