# 手動更新とアイコン

## 利用方法

Windowsのsetup版では、ロック中も「ヘルプ」→「バージョンと更新」から更新できます。

1. 「更新を確認」を押します。
2. バージョンと変更内容を確認し、「ダウンロード」を押します。
3. 「再起動して更新」を押します。保管庫をロックして画面操作なしで更新し、自動で再起動します。再起動後はマスターパスワードで解除してください。

未保存の編集は、保存してから再試行するか、確認画面で破棄を選びます。保存中は適用できません。OSの権限確認が必要な環境では、確認画面が表示されます。

「あとで」や通常終了では適用しません。起動時の更新確認・自動ダウンロードも行いません。アプリを起動し直した場合は手動で再確認・取得します。通信や署名の検証に失敗した場合は更新せず、再試行できます。

portable版・開発用のビルドは配布ページから入手します。

## Electron版からの移行

v0.8.0以前のElectron版からは、配布ページからv0.9.0以降のsetupを入手して実行します。setupはインストールの前にElectron版をElectron版自身のアンインストーラーで削除し、`%APPDATA%\CIPHER VAULT\data` の保管庫は残します。Electron版が起動していると、画面ありのsetupは終了を求める確認を出し、終了するまで先へ進みません。Electron版のportable版は登録されていないので削除されません。

Electron版のv0.7.0以前は、アプリ内更新でElectron版の最終版v0.8.0になります。v0.8.0は更新の確認をせず、配布ページを案内します。仕組みは[設計](設計.md#electron版からの移行)を参照してください。

## 配布の条件

公開手順と添付ファイルは[リリース手順](リリース手順.md)を参照してください。安定版のみを対象とし、同じ版への更新・ダウングレードは行いません。識別子（`io.github.termnix-it.ciphervault`）と保存先を維持します。

取得・署名の検証・適用は `tauri-plugin-updater` に任せ、独自のexe置換は行いません。更新情報は最新リリースの `latest.json` から読みます。ダウンロードしたsetupをminisignの署名で確かめ、`tauri.conf.json` の公開鍵と合わない更新や署名のない更新は適用しません。インストーラーは画面を出さずに（quiet）実行し、終わるとアプリを起動し直します。[更新フロー](ワークフロー/04-手動更新.md)も参照してください。

更新の署名は改ざんの検出のためのもので、Windowsのコード署名ではありません。配布物はコード署名していないため、SmartScreenの警告が出る場合があります。

## アイコン

原本は `build/icon.png` です。銀色の鍵と黒曜石をモチーフに、内蔵imagegenで作成した透過画像を使用します。変更後は次を実行します。

```powershell
./scripts/build-icons.ps1
```

16 / 24 / 32 / 48 / 64 / 128 / 256 pxの `build/icon.ico` と、画面・favicon用 `apps/web/public/icon.png` を生成します。Tauriは `tauri.conf.json` の `bundle.icon` に指定した `build/icon.ico` をexeとsetupに埋め込みます。ショートカットだけ古い場合はWindowsのアイコンキャッシュを確認してください。

## 検証

`npm run test:tauri-update` で、試験専用の製品名のsetupを2つの版で作り、実際の更新・自動再起動・同じ保管庫の再解除と、署名の合わない更新の拒否を確認します（[開発・配布手順](開発・配布手順.md#変更に応じた検証)）。この試験は使い捨ての鍵で署名するため、配布用の鍵での署名とGitHubからの取得は確かめられません。公開の前には、配布用の鍵で作った `latest.json` の署名を公開鍵で検証し、URLとタグが合っていることを確認します。利用中の保管庫は使わないでください。
