# 非公開ドキュメント

このディレクトリは、公開前の計画、個人的な作業メモ、内部向け資料、保守対象外の履歴資料を置くローカル専用領域です。

この `README.md` だけをGit管理し、その他のファイルとサブディレクトリは `.gitignore` で除外します。

## 注意

- Git管理外のため、別環境へcloneしても内容は復元されません
- 必要な文書は、秘密情報を含まないことを確認してから公開領域へ移します
- パスワード、APIキー、アクセストークン、秘密鍵、実際の保管庫データは保存しません
- 保存が必要な秘密情報には、適切なシークレット管理機能を使用します

公開可否の詳しい基準は[ドキュメント管理](../README.md)を参照してください。
