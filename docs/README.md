## 非公開文書

`docs/private/` はローカル専用です。ディレクトリの説明用 `README.md` だけをGit管理し、それ以外の内容は `.gitignore` で除外します。

## 公開・非公開の判断基準

### 公開する文書

次の条件をすべて満たす文書は公開領域に置きます。

- 利用者または開発参加者に継続して役立つ
- 内容が現在の実装と一致している
- インターネット上に公開されても問題がない
- 個人情報、認証情報、内部限定情報を含まない

例: セットアップ手順、設計概要、API概要、リリースノート、一般化されたワークフロー。

### 非公開にする文書

次のいずれかに該当する文書は `docs/private/` に置きます。

- 未確定または公開前の計画
- 個人的な作業メモや一時的な調査記録
- 公開前のロードマップや検討中の仕様
- 内部運用のためだけに必要な情報
- 完了済み計画のうち、公開文書として保守しない履歴資料

判断できない場合は、いったん非公開として扱います。

### 保存してはいけない情報

次の情報は公開・非公開を問わず、このディレクトリに保存しません。

- パスワード、APIキー、アクセストークン、秘密鍵
- 実際の保管庫データや復号済みデータ
- 公開許可を得ていない個人情報
- その他、漏えい時に認証やプライバシーへ影響する情報

秘密情報は環境変数、OSの資格情報管理、または適切なシークレット管理機能を使用します。

## 文書を追加・移動するとき

1. 上記基準で公開可否を判定する
2. 公開文書は `docs/` の該当カテゴリへ置く
3. 非公開文書は `docs/private/` へ置く
4. 公開文書を追加・移動した場合は、この索引と参照リンクを更新する
5. `git status --short --ignored` で追跡対象を確認する

## 見直しのタイミング

- リリース前
- アーキテクチャや保存方式を変更したとき
- 文書を公開領域へ移すとき
- 半年以上更新されていない計画を再利用するとき
