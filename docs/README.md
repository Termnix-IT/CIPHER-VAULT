## 公開・非公開の扱い

`docs/private/` 以外はリポジトリとともに公開します。現在の仕様・操作に継続して役立つ内容を置き、画面画像は `images/` にテスト用データで保存します。

`docs/private/` は未確定の計画・個人メモ・内部資料用です。説明用の `README.md` だけをGit管理し、それ以外は `.gitignore` で除外します。公開可否が不明な資料も、確認までは非公開にします。

公開・非公開を問わず、認証情報・秘密鍵・実際の保管庫や復号データ・公開許可のない個人情報を保存しません。秘密情報は環境変数やOSの資格情報管理などで扱います。

文書の追加・移動時は内容と参照先を確認し、この索引と関連リンクを更新します。`git status --short --ignored` で追跡対象を確認してください。リリース前や仕様変更時に古い説明を見直し、同じ説明を複数文書に維持しないようにします。
