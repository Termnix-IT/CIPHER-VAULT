# CIPHER VAULT v0.4.0

画面を落ち着いた見た目に作り直し、ボタンや案内の言葉を、使う人が知りたいことが伝わる表現に書き換えました。保存形式や暗号化の方式は変わらないため、今の保管庫をそのまま開けます。

## 改善

- 一覧・詳細・入力画面を作り直しました。閲覧時と編集時で欄の位置がそろい、空の欄は閲覧時に表示しません。項目の削除は、編集中に左下の「削除」から行います。
- 新しい項目は、検索欄の横の「＋」から追加します。種類は上部のタブで「ログイン」「APIキー」「カード」から選びます。グループ・タグ・メモは「＋ グループ・タグ・メモを追加」を押すと表示されます。
- 保管庫を初めて作るときは、マスターパスワードを2回入力します。入力が違うと作成しません。
- 「ツール」メニューを整理しました。「保管庫の管理」は「保管庫を更新…」「マスターパスワードを変更…」「保管庫を空にする…」に分かれました。「セキュリティ監査」は「パスワードの点検」、「接続の管理」は「外部アプリの接続」、「アプリ情報 / 更新」は「バージョンと更新」になりました。
- 「パスワードの点検」は、直したほうがいいもの（推測されやすい・使い回し）と、余裕があれば見直すものに分けて表示します。
- バックアップ画面は「書き出す」「読み込む」のタブに分かれました。
- 自動ロックしたときは、ロック画面に理由（5分間操作がなかった、スリープした など）を表示します。
- 画面上の「エントリ」は「項目」、「マスターキー」は「マスターパスワード」という呼び方にそろえました。

## 変わらないこと

パスワードは2回クリックで表示する、操作がないと自動でロックする、コピーした内容は30秒後かロック時に消える、の3つの動きは従来どおりです。保存形式・暗号化・バックアップファイルの形式も変わりません。

## 更新時の注意

v0.3.1のsetup版からは、「ヘルプ」→「アプリ情報 / 更新」から更新できます。更新後は、このメニューの名前が「バージョンと更新」になります。portable版は配布ページから新版を入手します。Windows配布物はコード署名されていません。Linux/macOSの評価パッケージは今回の公開対象に含めません。

## 配布物

- `CIPHER-VAULT-0.4.0-x64-setup.exe`：通常利用向け。
- `CIPHER-VAULT-0.4.0-x64-portable.exe`：インストール不要。
- `latest.yml` とsetup用 `blockmap`：アプリ内更新用。

## 検証

API・更新処理・画面の安全設定の回帰試験と、デスクトップ版の画面操作の統合試験を一時保管庫で実行しました。生成した公開用アプリでは、保存・新形式への移行・バックアップ・再起動後の保持・鍵消去を一時保管庫で確認しました。更新情報のファイル名・サイズ・SHA-512も検査しています。
