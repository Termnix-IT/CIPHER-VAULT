# CIPHER VAULT v0.2.6

詳細画面に「編集する」を追加し、閲覧と編集を切り替えられるようにしました。重複する表示や補足ラベルを減らし、確認・コピー・編集の操作を整理しました。同梱ランタイムも更新しています。

## 改善

- 一覧から選んだエントリは、まず閲覧用の詳細を表示します。右上の「編集する」、または「編集」→「選択中のエントリを編集」で入力欄に切り替わります。
- 「保存する」で変更を反映して閲覧に戻ります。「キャンセル」は未保存の変更があれば破棄を確認します。保存に失敗した場合は入力内容を保持します。
- コピー用の表示と編集フォームの二重表示を解消しました。グループ・タグ・メモも同じフォームで編集できます。
- 検索・一覧表示の切り替えを左側にまとめ、左下に「保管庫をロック」を配置しました。削除は詳細画面右上の「⋯」から実行します。
- 保存・キャンセルを右下に固定し、最小ウィンドウサイズでも操作できるようにしました。

## ランタイム

- Electronを41.10.7から45.0.0へ、同梱Node.jsを24.18.0から24.22.0へ更新しました。
- better-sqlite3を13.0.3へ更新し、Node-APIの同梱バイナリを使用します。
- Electronの変更に合わせ、クリップボードへの書き込み完了を待って成功を表示するようにしました。
- Web/API配布版の実行にはNode.js 22以上が必要です。Windowsデスクトップ配布版は、引き続きNode.jsの別途インストールは不要です。

## データと更新

- DB形式・暗号化・保存先の変更はありません。既存のマスターキーと保管庫を引き続き利用できます。
- パスワードの2回クリック表示と、保存・生成・閲覧と編集の切り替え・エントリ切り替え・ロック時に伏せ字へ戻す動作を維持します。
- setup版は「ヘルプ」→「アプリ情報 / 更新」から手動で更新できます。起動時の更新確認や通常終了時の自動適用はありません。
- portable版は新しい実行ファイルを取得して更新してください。

## 配布物

- `CIPHER-VAULT-0.2.6-x64-setup.exe`：通常利用向け。
- `CIPHER-VAULT-0.2.6-x64-portable.exe`：インストール不要。
- `latest.yml` とsetup用 `blockmap`：アプリ内の手動更新用。

Windows配布物はコード署名されていません。

## 検証

デスクトップビルド、API回帰テスト14件、更新テスト7件、IPC境界テスト2件が成功しました。一時保管庫を使い、Electron上で編集・保存、キャンセル、保存失敗時の入力保持、コピー、パスワード表示、グループ表示、新規追加のキャンセル、ロックを確認しました。最小サイズ1000×680でも保存ボタンが画面内に収まることを確認しています。

配布物内のサービスで保存・復号・ロック解除・バックアップ復元・監査を確認しました。DBと開発用ファイルの除外、setupと更新情報のSHA-512・サイズ一致も確認しています。実際の更新ライブラリを使い、ローカル配布先のv0.2.5→v0.2.6の検出・手動ダウンロード・チェックサム検証・自動インストールしないことを確認しました。
