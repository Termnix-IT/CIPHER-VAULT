# CIPHER VAULT v1.3.0

ほかのアプリを使っている最中でも、決めておいたキーでCIPHER VAULTを手前に呼び出せるようにしました。コンパクト表示は大きさを変えられるようになり、次に開くときも同じ大きさと位置で開きます。あわせて、情報の重要度が見分けやすくなるように画面の色と線を整え、確認のダイアログをアプリと同じ見た目にそろえました。保管庫の形式は変えていないので、v1.2.0で使っていた保管庫とバックアップをそのまま使えます。

## 追加

- 呼び出しキーを追加しました。「ツール」→「設定…」でキーを押して記録すると、ほかのアプリを使っているときもそのキーでCIPHER VAULTが手前に出て、検索欄にカーソルが移ります。もう一度押すと元のアプリへ戻ります。初期状態では無効です。
  - 選べるのは、Ctrl・Alt・Shiftのうち2つ以上と、英字・数字・F1〜F11・Spaceを組み合わせたキーです。Windowsキーを含む組み合わせと、アプリの中で使うCtrl+Shift+C・Ctrl+Shift+Mは選べません。
  - 「呼び出したときはコンパクト表示で開く」を選んでおくと、呼び出したときにコンパクト表示へ切り替えます。
  - ロック中に呼び出したときは、ロック画面を出してマスターパスワードの欄にカーソルを移すだけです。呼び出しキーで保管庫の解錠や、パスワードなどのコピー・表示はしません。呼び出しキーを変えるには、保管庫を解錠しておく必要があります。
  - ほかのアプリが同じキーを使っていると登録できないので、設定画面にその旨を表示します。そのときは別のキーを選んでください。
- コンパクト表示で、ウィンドウの端をドラッグして大きさを変えられるようにしました。幅は360〜520px、高さは400px以上にできます。大きさと位置は保存先フォルダの `window-prefs.json` に保存し、次にコンパクト表示にしたときも同じ大きさと位置で開きます。保存した位置のモニターを外したときは、ウィンドウがいまあるモニターの初期の位置で開きます。

## 改善

- 文字・線・面の明るさを、見出し・内容・補足などの役割ごとに使い分けました。シンプルとルミナスの両方のデザインに適用しています。
- 項目の詳細では、ログインID・パスワード・URLなどサインインに使う値を太めの等幅フォントで表示し、グループ・タグ・メモはその下に区切ってひと段控えめな色で表示するようにしました。
- アクセント色は、選択・フォーカス・主要な操作に限って使うようにしました。左の一覧では、選択中の行に色の線を付けず、面の明るさと文字の太さで選択を示します。
- 削除のボタンは、ポインターを重ねるかフォーカスしたときだけ赤く表示するようにしました。
- 「表示」メニューのアイコンを画面の形にして、パスワードを表示する目のアイコンと見分けられるようにしました。
- 項目の削除、保存していない変更の破棄、新しい項目の種類の変更、更新の適用の前に出す確認を、アプリと同じ見た目のダイアログにしました。これまでは、見出しに「tauri.localhost の内容」と出るブラウザのダイアログか、Windowsのメッセージボックスで確認していました。ダイアログを開いたときは「キャンセル」か「編集に戻る」にフォーカスがあり、Escキーでも取り消せます。確認ダイアログを出している間に保管庫がロックされたときは、ダイアログを閉じてからロック画面を出します。

## 更新のしかた

- v0.9.0以降のsetup版を使っている場合は、「バージョンと更新」から更新できます。
- v0.8.0以前のElectron版を使っている場合は、このリリースの `CIPHER-VAULT-1.3.0-x64-setup.exe` を実行してください。Electron版で「保管庫を更新」をしていない場合は、その前にElectron版でバックアップを書き出してください。

## 既知の制約

- Windows向けの配布物はコード署名されていません。起動時に「WindowsによってPCが保護されました」と表示された場合は、このリリースのページから入手したファイルであることを確かめてから、「詳細情報」→「実行」で起動してください。
- コンパクト表示では最大化できません。通常表示に戻してから最大化してください。
- 最大化ボタンをアプリで描いているため、ボタンにポインターを重ねたときのスナップレイアウトの候補は表示されません。画面の端へのドラッグやWin+Zでの配置は使えます。
- portable版を使うには、Microsoft Edge WebView2がインストールされている必要があります（Windows 11には標準で入っています）。

## 配布物

- `CIPHER-VAULT-1.3.0-x64-setup.exe`：通常利用向けのsetup版です。Electron版からの切り替えにも使います。
- `CIPHER-VAULT-1.3.0-x64-portable.exe`：インストールせずに使えるportable版です。
- `latest.json`：アプリがアプリ内更新で使うファイルです。
- `latest.yml`、`CIPHER-VAULT-0.8.0-x64-setup.exe` とその `blockmap`：v0.7.0以前のElectron版を、アプリ内更新でv0.8.0にするためのファイルです。v0.8.0は従来形式の保管庫からバックアップを書き出せます。

## 検証

Rust版の単体試験をし、実際のウィンドウで画面・CSP・IPCと保管庫の操作を試験しました。これらには、呼び出しキーの記録と拒否、コンパクト表示の大きさの変更と復元、アプリ内の確認ダイアログの動作（フォーカス、Escキーでの取り消し、ロック時に閉じること）も含みます。100件と500件の合成データで、一覧・検索・コンパクト表示・バックアップの速さを測りました。試験用に作った2つの版のsetupでアプリ内の更新を実際に行い、確認ダイアログで「破棄して更新」を選ぶと新しい版のアプリが自動で起動し直し、保管庫が残っていることを確かめました。
