# CIPHER VAULT v0.3.0

ログインに加え、APIキーとクレジットカードを種類別に保存できるようになりました。全項目を暗号化する保管庫への移行、マスターパスワード・鍵の更新、中断時の復旧をアプリから操作できます。

## 追加

- APIキーはキー本体と、任意のキーID・接続先URL・有効期限を保存できます。
- カードは番号と、任意の名義・有効期限・セキュリティコードを保存できます。暗証番号は扱いません。一覧には末尾4桁だけを表示します。
- キー・カード番号・セキュリティコードを個別に伏せ字表示し、2回の操作で表示、個別のボタンでコピーできます。
- 「ツール」→「保管庫の管理」から、新形式への移行・鍵更新・空の保管庫への切替を実行できます。移行元と復旧用ファイルを保持し、中断後は照合して復旧します。
- 「接続の管理」からローカルAgentの登録と取消を行えます。Codex向けMCPアダプターはソース側の手順で別途設定し、検索ごとの確認後にログイン・APIキーの名前とサイトのoriginだけを返します。秘密値は返さず、カードを除外します。

## データと互換性

- 従来形式はそのままログインに利用できます。APIキー・カードの追加には、全項目を暗号化する新形式への明示的な移行が必要です。新規の保管庫も従来形式で開始します。
- 移行・鍵更新前に暗号化バックアップを端末外にも保管してください。移行元のデータは残り、以前のパスワードで復号できるため、安全な消去ではありません。
- APIキー・カードを保存した保管庫は対応する新しい版で使用してください。未対応の旧版アプリは開けません。旧版で元の保管庫を編集しても移行先へは反映されません。
- 混在バックアップは新しいv2形式で書き出し、新形式の空の保管庫へ復元します。ログインだけのバックアップは既存のv1形式を維持し、既存バックアップも復元できます。
- パスワード監査はログインだけを対象とします。APIキー・番号全体・セキュリティコードは検索対象に含めません。

## 改善

- セッションの世代・期限と画面の権限制御を強化し、ロック後に遅い応答で秘密が再表示されることを防ぎます。
- ローカル接続にOSによる資格の保護、相互認証、登録の取消を適用します。
- 起動時の自動更新確認や通常終了時の自動適用は追加していません。

## 配布物

- `CIPHER-VAULT-0.3.0-x64-setup.exe`：通常利用向け。
- `CIPHER-VAULT-0.3.0-x64-portable.exe`：インストール不要。
- `latest.yml` とsetup用 `blockmap`：アプリ内の手動更新用。

Windows配布物はコード署名されていません。Linux/macOSのパッケージは評価用で、今回の製品リリースには含めません。ブラウザ自動入力・認証付き外部操作は対象外です。実電源断と公開リリース間のインストール・再起動は未検証です。

## 検証

API・保存・暗号互換・移行・復旧の回帰試験はNode.jsとElectronで各246件、WindowsのWeb配布試験は2件成功しました。MCP契約と実stdio接続、種類別フォームの実Electron操作、既存ログインと管理操作も確認しています。

v0.3.0の生成済みアプリをソース外へコピーし、独立した一時保管庫で実DPAPI・相互認証・移行・APIキーとカードの保存・混在バックアップ・再起動後の保持・鍵消去を確認しました。利用中の保管庫は検証に使っていません。setup・portable・更新情報・blockmapを生成し、setupのSHA-512・サイズ・更新先ファイル名の一致も確認しました。
