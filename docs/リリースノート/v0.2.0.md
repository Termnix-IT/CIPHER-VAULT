# CIPHER VAULT v0.2.0

Windows の setup 版に手動アップデートを追加し、鍵と黒曜石のアイコンを刷新しました。

## 追加

- Windows の setup 版に手動アップデートを追加。「アプリ情報」から確認・ダウンロード・再起動して更新できます。
- 未保存入力がある場合の確認と、更新を後回しにする操作に対応しました。
- アプリ情報にアイコンと現在のバージョンを表示します。
- マスターキーを忘れた場合に、確認操作を経て保管庫を完全リセットする機能を追加しました。リセットすると保存済みデータはすべて削除されます。

## 改善・修正

- 鍵と黒曜石の意匠を残したアイコンへ刷新しました。
- exe に Electron の標準アイコンが残るビルド設定を修正しました。
- タイトルバーとブラウザの favicon にアプリアイコンを表示します。
- エントリ検索の操作と、独自タイトルバーを追加しました。

## 移行

更新機能がない旧版では、アプリを終了し、新しい setup を同じインストール先へ上書きしてください。2026-09-15 に利用者による移行完了の報告を受けています。
起動時の更新確認、勝手なダウンロード、通常終了時の更新適用は行いません。更新操作時に GitHub へ接続しますが、保管庫の内容は送信しません。

## 配布物

- `CIPHER-VAULT-0.2.0-x64-setup.exe`: 通常利用向けの Windows x64 インストーラー。
- `CIPHER-VAULT-0.2.0-x64-portable.exe`: インストール不要の実行版。アプリ内更新は setup 版向けです。
- `latest.yml` と `CIPHER-VAULT-0.2.0-x64-setup.exe.blockmap`: 更新用ファイル。通常利用ではダウンロード不要です。

配布物はコード署名されていません。公開リリース間のインストール・再起動を含むアプリ内更新の通し確認は未実施です。
配布条件と検証範囲は [手動更新とアイコン](https://github.com/Termnix-IT/CIPHER-VAULT/blob/v0.2.0/docs/手動更新とアイコン.md) を参照してください。
