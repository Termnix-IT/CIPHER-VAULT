# CIPHER VAULT v1.0.1

保管庫の自動ロックとクリップボードの消去が、まれなタイミングで誤って動くことがあった問題を修正しました。保管庫の形式は変えていないので、v1.0.0の保管庫をそのまま開けます。

## 修正

- 複数の操作が同時に時刻を確かめたとき、時計が戻ったと誤って判定して、保管庫がロックされることがあったのを直しました。
- コピーしたパスワードを消す時刻の判定が、別のコピーと重なったときにずれることがあったのを直しました。
- 保管庫を切り替えるとき、前の保管庫のファイルを閉じ終えるのを待ってから切り替えるようにしました。
- 従来形式の保管庫で、エントリの更新日時が作成日時やパスワード変更日時より前にならないようにしました。すでに日時が前後している項目は、次に編集したときに直ります。

## 改善

- エントリの多い保管庫で、バックアップや監査のときに保管庫全体を読む処理を速くしました。

## 更新のしかた

- v0.9.0以降のsetup版を使っている場合は、「ヘルプ」→「バージョンと更新」から更新できます。
- v0.8.0以前のElectron版を使っている場合は、このリリースの `CIPHER-VAULT-1.0.1-x64-setup.exe` を実行してください。setupがElectron版をアンインストールしてから、保管庫を残したままインストールします。

## 既知の制約

- Windows配布物はコード署名されていません。起動時に「WindowsによってPCが保護されました」と表示された場合は、このリリースのページから入手したファイルであることを確かめてから、「詳細情報」→「実行」で起動してください。
- 最大化ボタンをアプリで描いているため、ボタンにマウスを重ねたときのスナップレイアウトの候補は表示されません。画面の端へのドラッグやWin+Zでの配置は使えます。
- portable版は、Microsoft Edge WebView2がインストールされている必要があります（Windows 11には標準で入っています）。

## 配布物

- `CIPHER-VAULT-1.0.1-x64-setup.exe`：通常利用向け。Electron版からの切り替えにも使います。
- `CIPHER-VAULT-1.0.1-x64-portable.exe`：インストール不要。
- `latest.json`：アプリ内更新用。
- `latest.yml`、`CIPHER-VAULT-0.8.0-x64-setup.exe` とその `blockmap`：v0.7.0以前のElectron版が、アプリ内更新でv0.8.0になるためのものです。

## 検証

Rust版の単体試験と、実際のウィンドウでの画面・CSP・IPCと保管庫の操作の試験を実行しました。署名付きの2つの版のsetupで実際に更新して、再起動後も保管庫が残ることを確かめました。
