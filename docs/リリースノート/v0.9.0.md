# CIPHER VAULT v0.9.0

デスクトップ版を、ElectronからRust（Tauri）で作り直したアプリに切り替えました。画面と操作はこれまでと同じで、保管庫の形式も変えていないため、今の保管庫をそのまま開けます。Electron版（v0.8.0以前）を使っている場合は、このリリースのsetupを実行すると、Electron版を自動でアンインストールして保管庫を引き継ぎます。

## 変更

- 保管庫の暗号化・保存・解除などの処理をRustで作り直しました。v0.8.0と同じ入力に同じ結果を返すことを、両方の実装を比べる試験で確認しています。
- アプリ内の更新は、ダウンロードしたsetupの署名を確かめてから適用します。署名がない、または合わない更新は適用しません。
- アプリは1つだけ起動でき、2つ目を起動すると先に開いているウィンドウを前面に出します。Electron版が起動している間は、同じ保管庫を開かずに理由を表示して終了します。
- バックアップの保存では、Windowsの保存ダイアログで保存先を選びます。

## Electron版からの切り替え

1. 念のため、Electron版の「ツール」→「バックアップ」で `.cvault` バックアップを保存します。
2. このリリースの `CIPHER-VAULT-0.9.0-x64-setup.exe` を実行します。Electron版が起動している場合は終了を求める確認が出るので、編集中の内容を保存して終了してから「再試行」を押します。
3. setupがElectron版をアンインストールしてから、Rust版をインストールします。保管庫（`%APPDATA%\CIPHER VAULT\data`）は削除しません。
4. Rust版を起動し、今までのマスターパスワードで開きます。

Electron版のportable版は自動では削除されません。不要になったら削除してください。Electron版のv0.7.0以前を使っている場合は、アプリ内更新でv0.8.0になってから、このリリースのsetupを入手できます。

## 既知の制約

- パスワードの点検で「推測されやすい」とする判定が、v0.8.0より少し甘くなります。日付や単語の並びのパターンを判定に使わないためです。点数の計算とほかの判定は同じです。
- portable版は、Microsoft Edge WebView2がインストールされている必要があります（Windows 11には標準で入っています）。setupは、WebView2がない環境ではインストールします。
- Windows配布物はコード署名されていません。初回の起動でSmartScreenの警告が出る場合があります。

## 配布物

- `CIPHER-VAULT-0.9.0-x64-setup.exe`：通常利用向け。Electron版からの切り替えにも使います。
- `CIPHER-VAULT-0.9.0-x64-portable.exe`：インストール不要。
- `latest.json`：Rust版のアプリ内更新用。
- `latest.yml`、`CIPHER-VAULT-0.8.0-x64-setup.exe` とその `blockmap`：v0.7.0以前のElectron版が、アプリ内更新でv0.8.0になるためのものです。

## 検証

Rust版の単体試験と、v0.8.0の実装との差分試験を実行しました。実際のウィンドウで画面・CSP・IPCと保管庫の操作を確認し、署名付きの2つの版のsetupで実際に更新して、再起動後も保管庫が残ることを確かめています。試験用の製品名で、合成データの保管庫を使ったElectron版のsetupからの切り替えとportable版の起動も確認しました。
