# CIPHER VAULT v1.0.0

最初の正式版です。Windows標準のタイトルバーをなくして、「ファイル」〜「ヘルプ」のメニューの列をタイトルバーにしました。ルミナスデザインでは、メニューの列にも光を通し、一覧と詳細のパネルの枠を見分けやすくしました。保管庫の形式は変えていないので、v0.9.0の保管庫をそのまま開けます。

## 変更

- ウィンドウ上部が2段（Windows標準のタイトルバーとメニュー）だったのを、メニューの列だけの1段にしました。右端の最小化・最大化・閉じるのボタンで操作し、メニューの空いたところをドラッグするとウィンドウを移動でき、ダブルクリックで最大化と元のサイズを切り替えます。バックアップなどのダイアログを開いている間も、ウィンドウの移動・最小化・最大化・閉じるは使えます。
- ルミナスデザインで、メニューの列が背景と同じ光の色になります。メニューを開いたときの見た目もルミナスに合わせました。
- ルミナスデザインで、右側の詳細のパネルと左側の一覧のパネルの枠を、背景より明るい色と影で表示します。詳細の各項目の区切り線も少し見やすくしました。

## 更新のしかた

- v0.9.0のsetup版を使っている場合は、「ヘルプ」→「バージョンと更新」から更新できます。
- v0.8.0以前のElectron版を使っている場合は、このリリースの `CIPHER-VAULT-1.0.0-x64-setup.exe` を実行してください。v0.9.0と同じく、setupがElectron版をアンインストールしてから、保管庫を残したままインストールします。

## 既知の制約

- Windows配布物はコード署名されていません。起動時に「WindowsによってPCが保護されました」と表示された場合は、このリリースのページから入手したファイルであることを確かめてから、「詳細情報」→「実行」で起動してください。
- 最大化ボタンをアプリで描いているため、ボタンにマウスを重ねたときのスナップレイアウトの候補は表示されません。画面の端へのドラッグやWin+Zでの配置は使えます。
- portable版は、Microsoft Edge WebView2がインストールされている必要があります（Windows 11には標準で入っています）。

## 配布物

- `CIPHER-VAULT-1.0.0-x64-setup.exe`：通常利用向け。Electron版からの切り替えにも使います。
- `CIPHER-VAULT-1.0.0-x64-portable.exe`：インストール不要。
- `latest.json`：アプリ内更新用。
- `latest.yml`、`CIPHER-VAULT-0.8.0-x64-setup.exe` とその `blockmap`：v0.7.0以前のElectron版が、アプリ内更新でv0.8.0になるためのものです。

## 検証

Rust版の単体試験と、実際のウィンドウでの画面・CSP・IPCと保管庫の操作の試験を実行しました。タイトルバーのボタンでの最大化と元に戻すこと、ダイアログを開いている間もウィンドウのボタンだけは使えること、閉じるボタンで保管庫をロックしてコピーを消してから終了すること、許可していないウィンドウ操作が拒否されることも確かめています。署名付きの2つの版のsetupで実際に更新して、再起動後も保管庫が残ることを確かめました。
