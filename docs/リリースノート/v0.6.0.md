# CIPHER VAULT v0.6.0

銀行・証券の情報を、ログイン用と取引用のパスワードに分けて保存できるようになりました。一覧からグループを作ったり項目を削除したりしやすくし、ウィンドウも必要な幅まで狭めました。今の保管庫はそのまま開けますが、銀行/証券を一度保存すると、その保管庫はv0.5.0以前のアプリでは開けなくなります。

## 追加

- 新しい項目の種類「銀行/証券」を追加しました。ログインIDとログインパスワードに加えて、取引パスワードと、第2暗証番号など名前を付けた秘密を最大8件まで保存できます。それぞれ伏せ字で表示し、個別にコピーできます。全項目を暗号化する新形式の保管庫で使えます。
- 検索欄の横のアイコンから、グループ名と対象の項目を指定して新しいグループを作れます。作成後はグループ別の表示に切り替わります。
- 一覧の項目を右クリック、またはメニューキーを押すと、「グループへ追加」「グループから削除」「項目削除」を選べます。右クリックでは選択中の項目は変わりません。
- 項目を選んだときの右上に、「編集」と並べて赤い「削除」ボタンを追加しました。編集に入らなくても削除できます。

## 改善

- ウィンドウの初期サイズを880×780、最小サイズを780×680に狭めました。詳細の各行は右ペインの幅いっぱいに伸びます。
- ロックは「ファイル」→「ロック」にまとめ、左下のロックボタンを外しました。
- マスターパスワードを間違えたときの表示を「マスターパスワードが正しくありません」だけにしました。
- 開いた画面の右上で、ウィンドウボタンの下の区切り線が途切れないようにしました。

## 更新時の注意

- **銀行/証券の保存は元に戻せません。** 最初の1件を保存すると保管庫の形式の印が上がり、その項目を削除した後もv0.5.0以前のアプリでは開けません。同じ理由で、銀行/証券を含むバックアップもv0.5.0以前では復元できません。銀行/証券を保存しなければ、形式は変わりません。
- グループの変更は項目を1件ずつ暗号化し直します。途中で失敗すると、処理済みの項目だけ変更後のまま残ります。その場合はエラーを表示し、一覧を読み直して実際の状態を表示します。
- v0.4.0以降のsetup版からは、「ヘルプ」→「バージョンと更新」から更新できます。portable版は配布ページから新版を入手します。Windows配布物はコード署名されていません。

## 配布物

- `CIPHER-VAULT-0.6.0-x64-setup.exe`：通常利用向け。
- `CIPHER-VAULT-0.6.0-x64-portable.exe`：インストール不要。
- `latest.yml` とsetup用 `blockmap`：アプリ内更新用。

## 検証

API・更新処理・画面の安全設定の回帰試験と、デスクトップ版の画面操作の統合試験を一時保管庫で実行しました。生成した公開用アプリでは、保存・新形式への移行・バックアップ・再起動後の保持・鍵消去を一時保管庫で確認しました。更新情報のファイル名・サイズ・SHA-512も検査しています。更新処理のコードはv0.5.0から変更しておらず、旧版からのインストーラーによる実更新は今回実施していません。
