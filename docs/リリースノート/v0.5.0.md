# CIPHER VAULT v0.5.0

保管庫を操作できるのは、アプリを操作している本人の画面操作だけにしました。そのため、ほかのアプリから保管庫へつなぐ「外部アプリの接続」を削除しました。保存形式や暗号化の方式は変わらないため、今の保管庫をそのまま開けます。

## 削除

- 「ツール」メニューの「外部アプリの接続」を削除しました。エージェントやブラウザ拡張を登録する画面、登録したアプリからの接続の受け付け、Codex（MCP）からの候補検索は使えなくなります。
- 接続のために同梱していた補助プログラム（`native-transport`）を配布物から外しました。

## 変わらないこと

パスワードは2回クリックで表示する、操作がないと自動でロックする、コピーした内容は30秒後かロック時に消える、の3つの動きは従来どおりです。保存形式・暗号化・バックアップファイルの形式も変わりません。

## 更新時の注意

以前の版で「外部アプリの接続」を有効にしたことがある場合、接続の登録情報がアプリのデータフォルダ内の `local-connections` に残ります。新しい版はこのフォルダを使わず、自動で削除もしません。不要であれば、アプリを終了してから手動で削除できます。保管庫本体（`data` フォルダ）は削除しないでください。
