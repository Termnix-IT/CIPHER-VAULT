# CIPHER VAULT v0.5.0

保管庫を操作できるのは、アプリを操作している本人の画面操作だけにしました。そのため、ほかのアプリから保管庫へつなぐ「外部アプリの接続」を削除しました。あわせて、画面に控えめな動きを加え、ダイアログの大きさを固定しました。保存形式や暗号化の方式は変わらないため、今の保管庫をそのまま開けます。

## 改善

- 保管庫を開いたとき、鍵のマークが開いてから一覧へ切り替わります。
- 一覧で項目を選ぶと、選択中の背景が新しい項目へ滑らかに移ります。
- パスワードなどをコピーすると、クリップボードから消えるまでの残り時間を円で表示します。
- 「バージョンと更新」「パスワードの点検」「バックアップ」などのダイアログは、中身が変わっても大きさが変わりません。内容が多いときはダイアログの中だけがスクロールします。開閉時はふわっと表示・非表示になります。
- 一覧の上の検索欄・件数と、一覧との間に、常に区切り線が入るようにしました。

動きを減らす設定（Windowsの「アニメーション効果」をオフ）にしている場合、これらの動きは表示しません。

## 削除

- 「ツール」メニューの「外部アプリの接続」を削除しました。エージェントやブラウザ拡張を登録する画面、登録したアプリからの接続の受け付け、Codex（MCP）からの候補検索は使えなくなります。
- 接続のために同梱していた補助プログラム（`native-transport`）を配布物から外しました。

## 変わらないこと

パスワードは2回クリックで表示する、操作がないと自動でロックする、コピーした内容は30秒後かロック時に消える、の3つの動きは従来どおりです。保存形式・暗号化・バックアップファイルの形式も変わりません。

## 更新時の注意

v0.4.0のsetup版からは、「ヘルプ」→「バージョンと更新」から更新できます。portable版は配布ページから新版を入手します。Windows配布物はコード署名されていません。

以前の版で「外部アプリの接続」を有効にしたことがある場合、接続の登録情報がアプリのデータフォルダ内の `local-connections` に残ります。新しい版はこのフォルダを使わず、自動で削除もしません。不要であれば、アプリを終了してから手動で削除できます。保管庫本体（`data` フォルダ）は削除しないでください。

## 配布物

- `CIPHER-VAULT-0.5.0-x64-setup.exe`：通常利用向け。
- `CIPHER-VAULT-0.5.0-x64-portable.exe`：インストール不要。
- `latest.yml` とsetup用 `blockmap`：アプリ内更新用。

## 検証

API・更新処理・画面の安全設定の回帰試験と、デスクトップ版の画面操作の統合試験を一時保管庫で実行しました。生成した公開用アプリでは、保存・新形式への移行・バックアップ・再起動後の保持・鍵消去を一時保管庫で確認し、外部接続用の補助プログラムが含まれないことも検査しました。更新情報のファイル名・サイズ・SHA-512も検査しています。
