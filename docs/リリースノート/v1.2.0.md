# CIPHER VAULT v1.2.0

毎日の操作を速くするための改善です。小さな窓で使えるコンパクト表示、自動ロックの時間の設定、登録したURLをブラウザで開く操作、キーボードショートカット、お気に入りと最近使用を追加しました。お気に入りか最近使用を一度でも記録すると、保管庫はv1.1.0以前の版で開けなくなります。旧版に戻す可能性がある場合は「保管庫の形式の変更」を読んでください。

## 追加

- コンパクト表示を追加しました。「表示」メニューか Ctrl+Shift+M で切り替え、幅400pxの窓で検索・一覧・詳細を使えます。詳細には、項目の種類に応じてログインID・パスワード・URLなど、ログインに使う欄だけを表示し、メモとタグは表示しません。ピンのボタンで、ほかのウィンドウより手前に表示し続けられます。通常表示に戻すと、元の大きさに戻ります。
- 自動ロックの時間を「ツール」の「設定…」で選べるようにしました。1分・5分・10分・15分・30分・1時間・2時間・無効から選べます。無効にすると時間ではロックしませんが、画面のロック・スリープ・アプリの終了では、これまでどおりロックします。
- 登録したURLを既定のブラウザで開けるようにしました。開けるのは http と https のURLだけで、ログインIDやパスワードをURLに付けることはしません。ユーザー名やパスワードを含むURLは開きません。
- お気に入りを追加しました。詳細の見出しの☆、一覧の右クリックメニュー、「項目」メニューで付け外しでき、一覧の☆のボタンでお気に入りだけに絞り込めます。コンパクト表示の一覧では、お気に入りを先頭に並べます。
- 最近使用を追加しました。ログインID・パスワードのコピーとURLを開く操作をした項目を、使った順に並べます。一覧の並べ替えの「最近使用順」と、コンパクト表示の一覧で使います。
- キーボードショートカットを追加しました。アプリの窓にフォーカスがあるときだけ働き、ほかのアプリの操作中には反応しません。

| キー | 操作 |
|---|---|
| Ctrl+F | 検索欄へ移動 |
| Ctrl+N | 新しい項目 |
| Ctrl+B | ログインIDをコピー |
| Ctrl+Shift+C | パスワード（カードの番号やAPIキーなど、項目の主な秘密）をコピー |
| Ctrl+U | URLをブラウザで開く |
| Ctrl+L | ロック |
| Ctrl+Shift+M | コンパクト表示の切り替え |

コピーとURLのショートカットは、保管庫がロックされているとき、項目を編集しているとき、ダイアログやメニューが開いているときには働きません。

## 改善

- マウスの移動とホイールは、アプリの窓にフォーカスがあるときだけ操作として数えるようにしました。背面に置いた窓の上をマウスが通っただけで、自動ロックまでの時間が延びることはありません。
- メニューの項目に、対応するショートカットを表示するようにしました。

## 保管庫の形式の変更

- 自動ロックの時間は、保存先フォルダの `app-settings.json` に保存します。v1.1.0から更新した場合は、これまでと同じ5分のままです。新しく作る保管庫は15分から始まります。
- お気に入りと最近使用の日時は、各項目と一緒に暗号化して保存します。最初に記録したときに保管庫の形式をv5に上げ、その前に保管庫を同じフォルダの `before-v5.sqlite` へ複製します。
- v5の保管庫は、v1.1.0以前の版では開けません。旧版に戻す必要があるときは `before-v5.sqlite` を使ってください（複製した後の変更は含まれません）。
- お気に入りか最近使用を含むバックアップ（`.cvault`）はv5になり、v1.1.0以前の版では読み込めません。この版は、これまでのどの版のバックアップも読み込めます。

## 更新のしかた

- v0.9.0以降のsetup版を使っている場合は、「バージョンと更新」から更新できます。
- v0.8.0以前のElectron版を使っている場合は、このリリースの `CIPHER-VAULT-1.2.0-x64-setup.exe` を実行してください。Electron版で「保管庫を更新」をしていない場合は、その前にElectron版でバックアップを書き出してください。

## 既知の制約

- Windows配布物はコード署名されていません。起動時に「WindowsによってPCが保護されました」と表示された場合は、このリリースのページから入手したファイルであることを確かめてから、「詳細情報」→「実行」で起動してください。
- コンパクト表示では最大化できません。通常表示に戻してから最大化してください。
- 最大化ボタンをアプリで描いているため、ボタンにマウスを重ねたときのスナップレイアウトの候補は表示されません。画面の端へのドラッグやWin+Zでの配置は使えます。
- portable版は、Microsoft Edge WebView2がインストールされている必要があります（Windows 11には標準で入っています）。

## 配布物

- `CIPHER-VAULT-1.2.0-x64-setup.exe`：通常利用向け。Electron版からの切り替えにも使います。
- `CIPHER-VAULT-1.2.0-x64-portable.exe`：インストール不要。
- `latest.json`：アプリ内更新用。
- `latest.yml`、`CIPHER-VAULT-0.8.0-x64-setup.exe` とその `blockmap`：v0.7.0以前のElectron版を、アプリ内更新でv0.8.0にするためのもの。v0.8.0は従来形式の保管庫からバックアップを書き出せます。

## 検証

Rust版の単体試験と、実際のウィンドウでの画面・CSP・IPCと保管庫の操作の試験を実行しました。自動ロックの設定、URLの拒否、お気に入り、ショートカット、コンパクト表示と手前に表示する操作も含みます。100件と500件の合成データで、一覧・検索・コンパクト表示・バックアップの速さを測りました。2つの版のsetupで実際に更新して、再起動後も保管庫が残ることを確かめました。
