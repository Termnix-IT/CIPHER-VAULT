# CIPHER VAULT v0.7.0

今までのシャープな見た目に加えて、やわらかく色が移り変わる「ルミナス」デザインを選べるようになりました。タイトルバーのメニューから開くダイアログも、文書のような配置からツールとして操作しやすい配置に変えました。保管庫の形式は変わらないため、今の保管庫はそのまま開けます。

## 追加

- 「表示」メニューで「シンプルデザイン」と「ルミナスデザイン」を切り替えられます。ロック画面でも切り替えられ、選んだデザインは次回の起動でも使われます。初めは今までと同じシンプルデザインです。
- ルミナスデザインでは、角を丸くした画面に、落ち着いた色のグラデーションがゆっくり移り変わって表示されます。OSで視覚効果を減らす設定にしている場合は、色の変化を止めます。

## 改善

- パスワードの点検は、左で問題の種類を絞り込み、右で該当する項目を確認する2列の画面にしました。点数はタイトルの行に表示します。
- バックアップ、マスターパスワードの変更、保管庫を空にする画面、バージョンと更新の画面は、左に項目名、右に入力欄や値を並べる配置にしました。
- 各ダイアログの大きさを固定し、表示する内容が変わっても大きさが変わらないようにしました。
- タイトルバーのメニュー項目の高さを詰めました。

## 更新時の注意

- v0.4.0以降のsetup版からは、「ヘルプ」→「バージョンと更新」から更新できます。portable版は配布ページから新版を入手します。Windows配布物はコード署名されていません。

## 配布物

- `CIPHER-VAULT-0.7.0-x64-setup.exe`：通常利用向け。
- `CIPHER-VAULT-0.7.0-x64-portable.exe`：インストール不要。
- `latest.yml` とsetup用 `blockmap`：アプリ内更新用。

## 検証

API・更新処理・画面の安全設定の回帰試験と、デスクトップ版の画面操作の統合試験を一時保管庫で実行しました。開発用のElectron環境では、両デザインの各ダイアログの表示を一時保管庫で確認しました。生成した公開用アプリでは、配布物の同梱内容と起動を試験し、更新情報のファイル名・サイズ・SHA-512も検査しています。更新処理のコードはv0.6.0から変更しておらず、旧版からのインストーラーによる実更新は今回実施していません。
