# CIPHER VAULT v1.1.0

タイトルバーをアイコンだけの1段にし、一覧の幅を変えたり折りたたんだりできるようにしました。項目ごとにアイコンを付けられます。あわせて保管庫の形式を整理し、v1.0.1以前の版やElectron版では、この版で使った保管庫を開けなくなる場合があります。更新の前に「保管庫の形式の変更」を読んでください。

## 追加

- 項目ごとのアイコンを設定できるようにしました。名前の頭文字・用意したシンボル・小さな画像から選び、16色から色を付けられます。詳細の見出しのアイコンか、一覧の右クリックメニューの「アイコンを変更…」から設定します。アイコンも項目と一緒に暗号化して保存します。
- 一覧の幅を境界線のドラッグや矢印キーで変えられるようにし、アイコンだけの1列に折りたためるようにしました。幅と折りたたみの状態は次の起動でも保たれます。
- ログインの項目のログインIDを、ほかのアプリへドラッグ＆ドロップできるようにしました。パスワードはドラッグできず、コピーだけです。

## 改善

- タイトルバーのメニューを文字からアイコンにし、名前はツールチップで表示するようにしました。「ファイル」と「編集」を1つの「項目」メニューにまとめ、ロックとバージョンと更新は1回の操作で開くボタンにしました。
- 新しい保管庫を、最初から全項目を暗号化する形式で作るようにしました。これまでは、パスワードとメモだけを暗号化する従来形式で作り、「保管庫を更新」で切り替える必要がありました。

## 保管庫の形式の変更

- v0.3.0以降の新形式の保管庫は、そのまま開けます。更新後に最初に開いたとき、保管庫を同じフォルダの `before-v4.sqlite` に複製してから、v1.0.1で設定したアイコンを各項目へ移します。
- アイコンを設定した項目がある保管庫は、v1.0.1以前の版とElectron版では開けません。旧版に戻す必要があるときは `before-v4.sqlite` を使ってください。
- アイコンを含むバックアップ（`.cvault`）は新しい版（v4）になり、v1.0.1以前の版では読み込めません。この版はこれまでのどの版のバックアップも読み込めます。
- 従来形式の保管庫は開けなくなりました。「保管庫を更新」と、ロック画面の「パスワードを忘れた場合」の完全リセットも削除しました。従来形式のファイルは削除せずに残します。
- 従来形式の保管庫が残っていると、ロック画面に案内が出ます。v1.0.1以前の版（Electron版を含む）でバックアップを書き出し、この版で新しい保管庫を作成してから、「ツール」の「バックアップ」で復元してください。

## 更新のしかた

- v0.9.0以降のsetup版を使っている場合は、「バージョンと更新」から更新できます。従来形式の保管庫を使っている場合は、先にバックアップを書き出してください。
- v0.8.0以前のElectron版を使っている場合は、このリリースの `CIPHER-VAULT-1.1.0-x64-setup.exe` を実行してください。setupがElectron版をアンインストールしてから、保管庫を残したままインストールします。Electron版で「保管庫を更新」をしていない場合は、その前にElectron版でバックアップを書き出してください。

## 既知の制約

- Windows配布物はコード署名されていません。起動時に「WindowsによってPCが保護されました」と表示された場合は、このリリースのページから入手したファイルであることを確かめてから、「詳細情報」→「実行」で起動してください。
- 最大化ボタンをアプリで描いているため、ボタンにマウスを重ねたときのスナップレイアウトの候補は表示されません。画面の端へのドラッグやWin+Zでの配置は使えます。
- 新しい保管庫の作成が途中で止まった場合、この版では自動で直せません。作成途中の保管庫は空なので、保存先の `vault-activation.json`・`vault-current.json` と `vaults` の中の該当フォルダを別の場所へ移せば、作り直せます。
- portable版は、Microsoft Edge WebView2がインストールされている必要があります（Windows 11には標準で入っています）。

## 配布物

- `CIPHER-VAULT-1.1.0-x64-setup.exe`：通常利用向け。Electron版からの切り替えにも使います。
- `CIPHER-VAULT-1.1.0-x64-portable.exe`：インストール不要。
- `latest.json`：アプリ内更新用。
- `latest.yml`、`CIPHER-VAULT-0.8.0-x64-setup.exe` とその `blockmap`：v0.7.0以前のElectron版を、アプリ内更新でv0.8.0にするためのもの。v0.8.0は従来形式の保管庫からバックアップを書き出せます。

## 検証

Rust版の単体試験と、実際のウィンドウでの画面・CSP・IPCと保管庫の操作（作成、アイコンの設定、マスターパスワードの変更を含む）の試験を実行しました。2つの版のsetupで実際に更新して、再起動後も保管庫が残ることを確かめました。
