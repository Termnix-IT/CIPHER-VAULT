# CIPHER VAULT v0.8.0

Electron版の最終版です。次の版からCIPHER VAULTはRust（Tauri）で作り直したアプリに切り替わるため、この版はアプリ内で更新せず、「ヘルプ」→「バージョンと更新」で配布ページを案内します。保管庫の形式と画面の操作は変わらないため、今の保管庫はそのまま開けます。

## 変更

- 「バージョンと更新」では更新の確認・ダウンロードを行わず、「このバージョンはアプリ内で更新できません」と表示します。「ダウンロードページを開く」を押すと配布ページを開きます。
- 次の版（Rust版）のsetupを実行すると、インストールの前にこのElectron版を自動でアンインストールします。保管庫（`%APPDATA%\CIPHER VAULT\data`）は削除せず、Rust版がそのまま開きます。Rust版を公開したら、配布ページからsetupを入手してください。

## 更新時の注意

- v0.4.0以降のsetup版からは、「ヘルプ」→「バージョンと更新」からこの版へ更新できます。portable版は配布ページから新版を入手します。Windows配布物はコード署名されていません。
- この版より後の更新は、配布ページから入手したsetupで行います。Rust版へ移る前に、念のため「ツール」→「バックアップ」で `.cvault` バックアップを保存しておくことをおすすめします。

## 配布物

- `CIPHER-VAULT-0.8.0-x64-setup.exe`：通常利用向け。
- `CIPHER-VAULT-0.8.0-x64-portable.exe`：インストール不要。
- `latest.yml` とsetup用 `blockmap`：v0.7.0以前のアプリ内更新用。

## 検証

API・更新処理・画面の安全設定の回帰試験を一時保管庫で実行しました。生成した公開用アプリでは、配布物の同梱内容と起動を試験し、更新情報のファイル名・サイズ・SHA-512も検査しています。試験用の製品名で作ったこの版のsetupを合成データの保管庫でインストールし、「バージョンと更新」がアプリ内更新を行わないこと、Rust版のsetupがこの版を削除して保管庫を残すことを確認しました。v0.7.0以前からこの版へのアプリ内の実更新は今回実施していません。
