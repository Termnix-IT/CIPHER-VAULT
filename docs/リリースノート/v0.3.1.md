# CIPHER VAULT v0.3.1

Windowsのsetup版で、更新の取得後に「再起動して更新」を押すと、インストーラーの操作なしで更新して自動再起動するようにしました。

## 改善

- 更新前に保管庫をロックし、更新後はマスターキーで解除して利用します。保存済みデータを引き継ぎます。
- 未保存編集の確認と「あとで」を維持します。起動時の更新確認・自動ダウンロード・通常終了時の自動適用は行いません。
- 更新画面の説明と開発・配布文書を簡潔にしました。
- CIの重複ビルド・監査と外部ライブラリ内部の重複テストを整理しました。保管庫・暗号・移行・復旧などの回帰試験は維持しています。

## 更新時の注意

画面操作なしの更新は、この版から行う更新で有効になります。v0.3.0以前から今回の版への更新は旧版の更新処理で行うため、従来のインストーラー画面が表示される場合があります。OSの権限確認が出る場合は確認してください。

portable版は配布ページから新版を入手します。Windows配布物はコード署名されていません。Linux/macOSの評価パッケージは今回の公開対象に含めません。

## 配布物

- `CIPHER-VAULT-0.3.1-x64-setup.exe`：通常利用向け。
- `CIPHER-VAULT-0.3.1-x64-portable.exe`：インストール不要。
- `latest.yml` とsetup用 `blockmap`：アプリ内更新用。

## 検証

専用の識別子・保管庫を持つ検証用setupに異なる版番号を付け、実際のサイレント更新・自動再起動・ロック状態での起動と、新形式のログイン・APIキーの保持を確認しました。未保存編集のキャンセル後も更新を保留でき、通常終了では適用されないことも確認しています。公開済みv0.3.0そのものからの無操作更新を確認したものではありません。

生成済みの公開用アプリでは、保存・移行・バックアップ・再起動後の保持・鍵消去を一時保管庫で確認しました。配布物の同梱・除外、更新情報のファイル名・サイズ・SHA-512も検査しています。
