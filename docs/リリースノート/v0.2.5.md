# CIPHER VAULT v0.2.5

既存の画面配置を保ち、エントリ選択・メニュー表示・保存とコピーの完了に短いアニメーションを追加しました。操作の移動や完了が分かりやすくなります。

## 改善

- 一覧の選択ラインが滑らかに移動します。検索・グループの折り畳み・スクロール・ウィンドウサイズ変更にも追従します。
- 詳細・編集画面は、選択した項目の上下方向に合わせて240msで切り替わります。
- メニュー・アプリ情報・ツールのダイアログが、短い移動と拡大で表示されます。
- 保存・コピーの成功時にチェックとシアンの光で完了を知らせます。処理の失敗時には成功の表示を出しません。
- OSの「動きを減らす」設定に対応します。詳細の表示途中で設定を変えた場合も動きを停止します。

## データと更新

- DB形式・暗号化・保存先の変更はありません。既存のマスターキーと保管庫を引き続き利用できます。
- パスワードの2回クリック表示と、保存・生成・選択変更・ロック時に伏せ字へ戻す動作を維持します。切り替えのために旧編集画面や画面のスナップショットを残さず、ロック時の非表示をアニメーション待ちで遅らせません。
- setup版は「ヘルプ」→「アプリ情報 / 更新」から手動で更新できます。起動時の確認や通常終了時の自動適用はありません。
- portable版は新しい実行ファイルを取得して更新してください。

## 配布物

- `CIPHER-VAULT-0.2.5-x64-setup.exe`：通常利用向け。
- `CIPHER-VAULT-0.2.5-x64-portable.exe`：インストール不要。
- `latest.yml` とsetup用 `blockmap`：アプリ内の手動更新用。

Windows配布物はコード署名されていません。

## 検証

デスクトップビルド、API回帰テスト14件、更新テスト7件、IPC境界テスト2件が成功しました。本番用npm依存の監査指摘は0件です。開発・ビルド用依存の監査を含む結果ではありません。

サンプルAPIを使ったブラウザと、配布物から展開した画面・サービスを使ったElectronで、選択ライン・上下方向の切り替え・保存とコピー・グループ表示・最小サイズ・メニューとアプリ情報・動きを減らす設定・パスワード表示とロック時の非表示を確認しました。ブラウザでは保存・コピーの失敗時に成功表示を出さないことと、表示途中の設定変更で動きを停止することも確認しています。

配布物のDB・秘密情報・開発ツールの除外、同梱サービスのバックアップ・復元・監査、同梱画面のIPC境界、setupと更新情報のSHA-512・サイズ一致を確認しました。実際の更新ライブラリで、ローカル配布先のv0.2.4→v0.2.5の検出・手動ダウンロード・チェックサム検証・自動インストールしないことを確認しました。
