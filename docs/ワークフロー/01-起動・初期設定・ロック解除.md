# 1. 起動・初期設定・ロック解除

初期設定・解除と自動ロックの流れです。鍵更新・中断後の復旧は[保管庫の管理サービス](../設計.md#保管庫の管理サービスと復旧専用起動)を参照してください。

```mermaid
flowchart TD
    start([アプリ起動]) --> mount[React Appをマウント]
    mount --> status[保管庫状態を取得]
    status --> configured{保管庫は設定済みか}

    configured -- いいえ --> setupScreen[初期設定画面を表示<br/>従来形式のファイルがあれば案内]
    setupScreen --> setupInput[マスターパスワードを入力]
    setupInput --> setupValid{12文字以上か}
    setupValid -- いいえ --> setupError[入力エラーを表示]
    setupError --> setupInput
    setupValid -- はい --> setupGate[共有実行枠・待機期限を確認]
    setupGate --> wrapRoot[root鍵を生成し<br/>scryptの鍵でpassword slotへ包む]
    wrapRoot --> setupEpoch{開始時と同じ世代か}
    setupEpoch -- いいえ --> cancelled[一時鍵を破棄し要求を取消]
    setupEpoch -- はい --> createDb[(vaults/vaultId/vault.sqliteを作成し<br/>開き直して確認)]
    createDb --> select[(受領記録とpointerを保存)]
    select --> keepKey[root鍵をメモリに保持]
    keepKey --> unlocked

    configured -- はい --> unlockedCheck{ロック解除済みか}
    unlockedCheck -- いいえ --> unlockScreen[ロック解除画面を表示]
    unlockScreen --> unlockInput[マスターパスワードを入力]
    unlockInput --> unlockGate[共有実行枠・待機期限を確認]
    unlockGate --> unwrap[password slotを開く]
    unwrap --> unlockEpoch{開始時と同じ世代か}
    unlockEpoch -- いいえ --> cancelled
    unlockEpoch -- はい --> verified{slotの認証に成功したか}
    verified -- いいえ --> unlockError[認証エラーを表示]
    unlockError --> unlockInput
    verified -- はい --> entriesOk[全entryを認証・検証]
    entriesOk --> keepKeyUnlock[root鍵をメモリに保持]
    keepKeyUnlock --> icons{v1.0.1までの<br/>アイコンのファイルがあるか}
    icons -- はい --> adopt[保管庫を複製し<br/>アイコンを各entryへ移す]
    adopt --> unlocked
    icons -- いいえ --> unlocked

    unlockedCheck -- はい --> unlocked[ロック解除状態]
    unlocked --> list[エントリ一覧を取得]
    list --> dashboard[ダッシュボードを表示]

    dashboard --> activity{ユーザー操作あり}
    activity -- はい --> resetTimer[現在の世代でCoreへ操作通知]
    resetTimer --> dashboard
    activity -- 5分間なし --> autoLock[Coreのタイマーまたは操作入口で失効]
    dashboard -->|手動ロック| manualLock[手動ロック]
    autoLock --> clearKey[メモリ上の保管庫鍵を破棄]
    manualLock --> clearKey
    clearKey --> invalidate[世代変更を通知し旧応答と表示を破棄]
    invalidate --> unlockScreen
```

## 状態に関する注意

password slotはDB、解除状態・鍵・世代・5分の期限は中核のセッション（`crates/vault-core/src/session.rs`）が保持します。通常APIや状態確認では期限を延長せず、期限後の操作通知でも再解除しません。再起動・画面ロックやスリープの通知・ウィンドウ終了・画面のプロセス喪失でロックし、自動解除は行いません。

初期設定・解除の同時実行、認証失敗時の待機、導出中の取消は[マスターパスワード](../設計.md#マスターパスワード)、作成と保管庫の選択は[新規作成と保管庫の選択](../設計.md#新規作成と保管庫の選択)、アイコンの取り込みは[一覧のアイコン](../設計.md#一覧のアイコン)を参照してください。
